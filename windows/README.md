# MobileVision Windows 客户端

Android 手机拍照后，Windows 自动接收、保存并展示原始 JPEG。当前已实现 Windows 端首个可运行版本，Android 客户端已实现，见 ../android/README.md。

## 启动

已打包程序：`release/win-unpacked/MobileVision.exe`。双击运行即可，不需要安装 Node.js。分发时必须保留整个 `win-unpacked` 文件夹，不能只复制 exe。当前为未签名的开发预览版，尚未制作安装程序。

在 windows 文件夹中执行开发命令：

```powershell
npm.cmd ci
npm.cmd start
```

首次启动会在当前 Windows 用户的图片目录下创建 MobileVision 文件夹；可以在界面中更改。配置、证书、配对凭据的哈希和 SQLite 索引保存在 Electron 的用户数据目录中。原图保存在用户选择的位置，不会因为更换目录而迁移或删除历史照片。

## 已实现

- HTTPS 本地接收服务、一次性二维码配对、证书 SHA-256 指纹、设备凭据认证、解除配对。
- 选择网卡地址，排除 169.254 自动私有地址，优先普通网卡；仍需用户确认所选地址能被手机访问。
- JPEG 原文件上传、50 MiB 大小限制、6000 万像素解码限制、哈希与图片有效性校验。
- SQLite 持久化去重、流式写盘、临时文件恢复、错误码反馈。
- 最新照片大图、缩略图历史、自动显示开关、缩放、定位文件、保存目录选择。
- 界面沙箱、上下文隔离、受限 IPC；接收服务不向网络开放照片浏览或任意文件读取接口。

## 验证命令

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run smoke
npm.cmd run pack
```

- `test`：HTTPS 集成测试，包括未授权拒绝、令牌刷新、连续 20 张上传、重复去重、原图一致、坏图与错误哈希拒收、重启恢复、解除配对。
- `smoke`：隐藏启动实际 Electron，模拟 Android 配对并上传样图，验证主图和缩略图完成加载、界面不能访问 Node；截图和报告写入 `test-results`，测试数据单独位于 `.smoke-data`。
- `pack`：构建可运行 Windows 程序目录，输出至 `release/win-unpacked`。

## 当前验证结果与边界

2026-09-13：本机 Node.js 25.2.1、npm 11.13.0、Git 2.47.1；Electron 44.3.0 内置 Node.js 24.20.0。依赖版本通过 package-lock.json 固定。

TypeScript 检查、2 项接收端集成测试、开发态 Electron 冒烟测试和打包后的 MobileVision.exe 冒烟测试均已通过。Windows 真实窗口已显示测试图片并生成缩略图。打包版本退出码为 0，详情见 `test-results/smoke.json`，截图见 `test-results/windows-empty.png` 和 `test-results/windows-photo.png`。

尚未验证 Android 真机扫码、手机到电脑的局域网互通、Windows 防火墙放行、真实手机 EXIF 样张、磁盘满、不同电脑安装以及传输延迟目标。模拟请求通过不代表手机端已经完成。

首版同一时间串行接收一张照片，忙时返回 RECEIVER_BUSY，手机端需重试。列表最多显示最近 500 张，原文件不会因列表上限删除。手机应每 10 秒请求 status；界面以最近 30 秒内的认证请求作为在线依据。

接收端首次使用随机端口并持久化，重启优先复用该端口；若端口被占用则另选端口，手机可扫描桌面“手机连接地址变化？”中的二维码更新地址；原配对凭据和待传队列保留，且必须匹配原电脑 ID 与证书。证书有效期一年，当前尚无证书到期自动更新功能。

## Windows 多选删除

在最近接收区域点击“多选删除”，逐张勾选或全选当前列表，再点击“删除所选”。系统弹窗确认后永久删除所选电脑原图、缩略图和记录，不进入回收站；手机副本保持不变。最多选当前列表 500 张。清理失败可重试，中断删除在重启后继续。4 项接收集成测试通过；软件渲染模式下桌面冒烟验证了多选状态与删除后预览更新。测试只使用隔离样图。

## 2026-09-23 桌面图片交互与截图

预览区支持围绕鼠标位置滚轮缩放（最高 800%）、左键拖动平移、双击适应窗口。点击“截图”后拖动框选，再点“保存截图”另存为 PNG；Esc 或“取消截图”退出。按经过 EXIF 方向纠正的原图像素导出，选区边缘向外取整；原照片保持不变。开始滚轮、拖动或截图会关闭自动显示新照片，防止操作时切图。截图为独立文件，不加入接收历史。

类型检查和 5 项单元/集成测试通过；真实 Electron 输入验收覆盖滚轮、拖动、框选、保存、删除与预览更新。截图测试覆盖旋转照片、越界拒绝、输出像素与原文件保持不变。

## 2026-09-23 截图操作调整

进入截图模式后拖动框选。双击选区直接将 PNG 图片复制到系统剪贴板；点击保存图标才打开另存为对话框并生成 PNG 文件。双击选区外不会复制。两条路径共用原图像素裁切与方向修正，原照片不变。

照片区域右键可直接进入截图模式。已有截图框可以按住左键整体拖动来对准内容，拖动时照片保持不动；截图框不会移出原图。双击截图框复制后会自动退出截图模式。

进入截图模式时会立即显示半透明蒙版。截图框内使用可拖动手势，按住时切换为正在拖动手势；截图框外保留十字手势用于重新框选。

截图模式下，在半透明蒙版区域右键即可退出：尚未框选时整张蒙版均可退出；框选后在截图框外右键退出。截图框内部始终显示移动光标，按下拖动时也保持一致。

蒙版只覆盖一次完整的照片显示组件。截图模式下右键任意位置均退出，截图框内部也一样。截图框静止时为点击手形光标，拖动过程中为抓取手形；框外继续显示十字光标。

开始框选时，整层蒙版会直接切换为选区外遮罩，避免两层短暂叠加造成颜色闪烁。截图框四角提供缩放点，可拖动任意角调整选区大小。
